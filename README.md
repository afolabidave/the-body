# THE BODY — Entire Silhouette Atelier

Online fashion storefront for **THE BODY**, designed with a Warm & Organic Lifestyle aesthetic (oat milk, travertine sand, terracotta, sage, and espresso) and built with **Next.js + Tailwind CSS**.

## Wardrobe Pillars

1. **Homestay Sanctuary** — Organic waffle robes, enzyme-washed Belgian linen trousers, cashmere lounge knits.
2. **Kinetic Activewear** — Four-way compression tanks, zero-seam high-rise leggings, 3D bamboo bodysuits.
3. **Urban Streetwear** — 500GSM sun-faded boxy hoodies, articulated ripstop cargo trousers, duck canvas chore coats.
4. **Atelier Resort & Evening** — Bias-cut peace silk slip dresses, unstructured herringbone linen blazers, plissé column skirts.
5. **Sculptural Jewelry** — Lost-wax molten bronze clavicle collars, hammered cuffs, travertine stone drop earrings, signet ring trios.
6. **Grounded Footwear** — Anatomical cork-footbed suede mules, Vibram® hemp desert runners, algae bio-foam slides, handwoven huarache loafers.

## Key Storefront Features

- **Interactive Anatomical Body-Zone Map**: Filter pieces directly by clicking body zones on the human silhouette (Neck & Collar, Torso & Core, Wrists & Hands, Legs & Stride, Foundation & Sole).
- **"Dress The Entire Body" 4-Zone Outfit Builder**: Mix and match Upper Body, Lower Body, Sculptural Jewelry, and Grounded Footwear with automatic **15% Full-Body Bundle Privilege**.
- **Quick-View Modal & Slide-Out Wardrobe Bag**: Inspect fabric architecture, organic dye swatches, saved looks, wishlist, and full checkout simulation.
- **Atelier Admin & Inventory Dashboard**: Manage stock levels, edit pricing, launch new pieces live, and track customer orders.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3005](http://localhost:3005) in your browser.
